# Rudra Soni — Interview Projects

Built with plain **HTML, CSS and JavaScript** (no libraries) plus one **WordPress theme**.

| # | Project | What it shows |
|---|---------|---------------|
| 1 | `01-peoplehub` | Employee directory: live search, filter, sort, modal, responsive grid |
| 2 | `02-leavedesk` | Leave management: form validation, balance logic, approve/reject, localStorage |
| 3 | `03-salary-calculator` | Salary breakup + PF / PT estimate, print-ready payslip |
| 4 | `04-saas-landing` | Responsive landing page: sticky nav, mobile menu, pricing toggle, FAQ |
| 5 | `05-wordpress-theme/rudra-business` | Custom WordPress theme: menus, widgets, loop, templates |

Each of projects 1-4 is a single `index.html`. Open it in a browser or deploy the folder to Vercel.
For the WordPress theme, zip the `rudra-business` folder and upload it in **Appearance > Themes > Add New > Upload Theme**.
